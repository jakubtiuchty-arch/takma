5G, IP68, hot-swap baterii 5000/7000 mAh. Terminal M3 SM30, SM30 M3 Mobile, kolektor

**Krytyczny problem — identyczny wzorzec jak SM24/SM25:**

## 3. Schema / Dane strukturalne (72/100)

### Obecne schematy
| Schema | Status | Uwagi |
|---|---|---|
| Product | ✅ | name, description, image (4), brand, manufacturer, model, sku, mpn, weight, additionalProperty (12+) |
| FAQPage | ✅ | 11 pytań, odpowiedzi z linkami wewnętrznymi |
| BreadcrumbList | ✅ | Poprawna ścieżka nawigacji |
| WebPage | ✅ | Informacje o stronie |
| Organization | ⚠️ × 2 | **Duplikat** — dwa identyczne bloki Organization |
| WebSite | ⚠️ × 2 | **Duplikat** — dwa identyczne bloki WebSite |

### Product schema — szczegóły

**Mocne strony:**
- 12+ additionalProperty (wymiary, procesor, OS, RAM, flash, wyświetlacz, skaner, NFC, Wi-Fi, Bluetooth, bateria, IP, upadki, temperatura)
- brand + manufacturer jako osobne obiekty
- weight z unitCode GRM
- 4 obrazy produktu
- sku i mpn ustawione na konkretny PN (SM300E-U2CFSS-HF)

**Krytyczny brak — Offers ❌:**
Product schema **nie zawiera sekcji `offers`**. Mimo że produkt jest "Dostępny" z 4 wariantami, brak:
- `offers` → `AggregateOffer` z `lowPrice` / `highPrice`
- `availability: InStock`
- `priceCurrency: PLN`

Porównanie z SM24, który ma wzorcowy `AggregateOffer` z 2 wariantami (SM24W 3 123 zł / SM24X 3 552 zł) — SM30 ma "Na zapytanie", ale **nadal powinien mieć Offers z `availability: InStock`** i `priceSpecification` wskazującą "Na zapytanie" lub minimum `availability`.

**Rekomendacja:** Dodać co minimum:
```json
"offers": {
  "@type": "AggregateOffer",
  "offerCount": 4,
  "availability": "https://schema.org/InStock",
  "priceCurrency": "PLN",
  "seller": {
    "@type": "Organization",
    "name": "TAKMA"
  }
}
```

### Duplikaty Organization × 2 i WebSite × 2 ❌
Identyczny systemowy bug jak na SM24, SM25 i stronie Citizen. Dwa identyczne bloki `Organization` i dwa identyczne bloki `WebSite` w kodzie strony. To bug w layout/template Next.js — prawdopodobnie jeden blok w `_app` / layout i drugi w komponencie strony.

**Priorytet: WYSOKI** — naprawić globalnie, dotyczy całej witryny.
