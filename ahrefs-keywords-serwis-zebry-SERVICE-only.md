# Keywords dla serwis-zebry.pl — SERVICE INTENT ONLY

## Korekta założeń

Po feedbacku — serwis-zebry.pl to **portal SERWISOWY**, nie sklep ani poradnik. Keywords skupione na:
- **serwis** (gdzie naprawić)
- **naprawa** (jak naprawić, koszt, gdzie)
- **usterka / problem** (jak rozwiązać)
- **wymiana części** (głowica, bateria, ekran)
- **diagnostyka**
- **gwarancja / OneCare**
- **lokalne** (serwis w mieście)

**Nie dodajemy** keywords typu „instrukcja", „sterowniki", „ZPL viewer", „program do etykiet", „setup utility" — to informational/poradnikowe, mimo że niektóre rankują (zostawiamy istniejące, ale nie budujemy więcej).
